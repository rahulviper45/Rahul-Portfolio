# Rahul Verma // Graphic Designer & Visual Artist Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Frahulviper45%2FRahul-Portfolio)

A state-of-the-art, interactive portfolio showcasing graphic design, advertising creatives, commercial video campaigns, print collateral, website hero banners, and vector illustration artwork.

---

## 🌟 Key Features

- **Cinematic 300-Frame 2D Canvas Engine**: Scroll-driven video canvas with fluid LERP physics interpolation for high-DPI displays.
- **Global Momentum Smooth Scroll**: Lenis/Locomotive-inspired smooth inertia scroll with a natural `0.8s ease-out` deceleration curve.
- **Hero Interactive Parallax & Zoom**: Multi-layered mouse float, depth-of-field blur, and subtle camera zoom on Rahul's visual portrait.
- **5 Dedicated Portfolio Category Suites**:
  1. **Creative Ads**: High-performance advertising campaigns and commercial banners (Zandu Shilajit, etc.).
  2. **Video Ads**: Video commercials with embedded HD HTML5 video player, play/pause controls, and volume toggles (Zandu Good Gut Campaign).
  3. **Print Media**: Retail leaflets, product brochures, shelf strips, and packaging collateral (Happy Jars Afters).
  4. **Website Creatives**: High-impact e-commerce storefront banners and hero creatives.
  5. **Illustration**: Original vector artwork and pop-culture tributes (Lunar Divide, The Viper, The Game).
- **Interactive Modals & Fullscreen Lightbox**: Project details modal with tag metadata, zoomable image lightbox, keyboard navigation (`Esc`, `←`, `→`), and category filtering.
- **Scroll-Triggered Reveals**: Staggered cascading animations for stats cards, live number counter roll-up, and horizontal fill animations for creative tools (Photoshop, Illustrator, Premiere Pro, After Effects, Blender).

## 🚀 Quick Deployment to Vercel

This repository is pre-configured with [`vercel.json`](./vercel.json) for 1-click deployment on [Vercel](https://vercel.com/):

1. Go to [Vercel Dashboard](https://vercel.com/new).
2. Import this repository: `rahulviper45/Rahul-Portfolio`.
3. Keep the default settings (Framework: **Other** / Root Directory: `./`).
4. Click **Deploy**!

### Vercel Features Configured
- **`cleanUrls: true`**: Clean, professional URLs (e.g. `/portfolio/creative-ads` instead of `/portfolio/creative-ads.html`).
- **CDN Caching**: Long-term caching for static assets, images, and fonts (`Cache-Control: public, max-age=31536000, immutable`).
- **HTTP Range Support**: Byte-range headers enabled for smooth MP4 commercial video streaming on Vercel's global edge network.

## 💻 Local Development

Run locally using Node.js:

```bash
# Start the local server
node server.js
```

Or using npm:

```bash
npm start
```

Then open your browser to **`http://localhost:3000`**.

- **Frontend**: Vanilla HTML5, Modern CSS3 (CSS Custom Properties, Glassmorphism, CSS Grid & Flexbox), Vanilla JavaScript (ES6+)
